This folder is for the price-taker optimization for fossil generators in the RTS-GMLC dataset.



\## Package Used

The optimization model uses the following package:  

👉 \[IDAES Price-Taker Module (Xinhe-Chen Repo)](https://github.com/Xinhe-Chen/idaes-pse/tree/various\_startup/idaes/apps/grid\_integration/pricetaker)



The branch at Xinhe's repo supports multiple types of startup (cold, warm and hot). Currently, it is merged into the idaes main.
