This folder is for the price-taker optimization for fossil generators in the RTS-GMLC dataset.

The Price-taker model used is adapted from the current idaes.apps.grid_integration.PriceTaker.

general_gen_model.py corresponds to price_taker_model.py. Unit_Commitment.py  corresponds to unit_commitment.py.



## Warning

Do not use these scripts; instead, use scripts under the Determinstic\_PT folder.
