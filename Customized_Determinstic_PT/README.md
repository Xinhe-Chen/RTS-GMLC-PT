This folder is for the price-taker optimization for fossil generators in the RTS-GMLC dataset.



The Price-taker model used is adapted from the current idaes.apps.grid\_integration.PriceTaker.



general\_gen\_model.py corresponds to price\_taker\_model.py. Unit\_Commitment.py  corresponds to unit\_commitment.py.



\# Warning

Do not use these scripts; instead, use scripts under the Determinstic\_PT folder.
